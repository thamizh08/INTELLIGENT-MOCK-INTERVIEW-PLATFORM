INTELLIGENT MOCK INTERVIEW PLATFORM

An Adaptive AI-Powered Technical Assessment and Remediation System

ABSTRACT

Technical interviews present severe cognitive anxiety, subjective evaluation, and lack realistic domain evaluation in traditional preparation portals.

This project presents the Intelligent Mock Interview Platform, an adaptive AI-orchestrated web application engineered to simulate rigorous technical recruitment assessments across 20+ engineering roles.

Built with React 18, Express.js, and MongoDB, it couples multi-provider cloud LLMs (OpenAI GPT-4o-mini & Google Gemini 1.5 Flash) with an autonomous offline fallback engine.

The platform automatically generates diagnostic radar analytics and synthesizes customized 7-day remediation roadmaps, achieving an 88.5% scoring correlation against expert human interviewers.

INTRODUCTION

Modern technical recruitment prioritizes architectural reasoning, concurrency defense, and verbal articulation over rote algorithmic memorization.

Traditional preparation platforms rely on static multiple-choice questions or binary unit test runners, leaving over 70% of engineering graduates experiencing interview anxiety without access to senior mentors.

Our platform bridges this pedagogical gap by providing realistic, real-time speech and text interview rehearsals with multi-criteria rubric grading.

Dynamic question branching and structured feedback empower candidates to systematically identify and resolve domain knowledge deficits.

OBJECTIVES
  • Requirement Modeling: Map hiring rubrics across 20+ technical roles and 3 experience seniority tiers.
  • Modular System Design: Build a decoupled 4-tier full-stack system with Express.js, React 18, and MongoDB.
  • Resilient AI Orchestration: Deploy a multi-provider gateway with OpenAI, Gemini, and offline rule-based fallback.
  • Interactive Analytics: Implement Web Speech API audio capture, Recharts radar charts, and 7-day study roadmaps.
  • Empirical Validation: Execute 52 QA test suites (100% pass rate) and validate scoring against human interviewers.

DISCUSSION
  • High Evaluation Fidelity: Automated multi-axis scoring achieved strong correlation (r = 0.885, MAE = 0.46) with senior human interviewers across core technical disciplines.
  • Zero-Downtime Resilience: Autonomous offline fallback engine guarantees sub-second evaluation (680 ms) during cloud network throttling or API downtime.
  • Closed-Loop Actionability: 7-day remediation roadmaps directly convert diagnostic deficits into daily, verified learning tasks with direct documentation links.
  • Operational Scope: Current implementation focuses on speech transcription and text reasoning; facial emotion analytics is slated for future release.
